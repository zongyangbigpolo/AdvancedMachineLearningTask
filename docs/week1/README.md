# Week 1：从字节到 0.1B 教学训练

这里把“能运行”“能解释”“有实验证据”放在同一张任务表里。面向熟练工程师，不再介绍 Python 基础语法；重点解释每条语句在语言模型流水线中的作用、张量形状和工程约束。

## 七天的学习与交付

| 天 | 实践任务 | 验收证据 |
| --- | --- | --- |
| Day 1 | 逐步实现 byte BPE，手算 merge，测试中英文与 emoji 的可逆编码 | `TokenizerTests`；[分词逐行讲解](tokenizer.md) |
| Day 2 | 建立文档、EOS、二进制 token 和 next-token batch 契约 | `test_data_shift_and_integrity`；[数据逐行讲解](data.md) |
| Day 3 | 实现 Linear / RMSNorm / RoPE / causal Attention | 前向和梯度 oracle、因果性；[模型逐行讲解](model.md) |
| Day 4 | 接通 SwiGLU、残差、共享 embedding、手写 CE | 单 batch 过拟合；[模型逐行讲解](model.md) |
| Day 5 | 接通训练、验证、学习率、梯度累积、checkpoint | CPU 中断与连续训练精确对照；[训练逐行讲解](train.md) |
| Day 6 | 在 Mac 上真实训练 98,323,200 参数的模型，固定教学预算 | [运行方法](runbook.md)；实际结果见 `reports/week1/` |
| Day 7 | 生成 Demo、分析不足、整理可复现实验与代码讲解 | [生成逐行讲解](generate.md)、[测试阅读指南](tests.md) |

“七天”是学习安排，不是后台定时任务，也不意味着可以在任何设备上七天完成充分预训练。已提供的 Mac 实验是 **100 updates × 1 batch × 128 tokens = 12,800 训练 token**，不是 20,000 步的大预算配置。它真实更新一亿级模型参数，但只能证明端到端工程链路，不能宣称语言能力或收敛质量合格。

## 怎么读逐行文档

每份文档的行号对应同目录链接指向的源码。空行只做排版，连续的参数、字典项和闭合括号有时放在同一个表格行中，但会说明各项含义。不要把文档当成必须背诵的 API 清单：一边看源码，一边用小 batch 加断点，验证形状、值和状态。

推荐主线：`tokenizer → data → model → train → generate`。额外的数据下载器见 [TinyStories 逐行讲解](tinystories.md)。测试代码与配置、依赖、忽略规则分别见 [测试阅读指南](tests.md)、[配置与工程文件](configuration.md)。

## 三个不能混淆的完成标准

1. **组件完成**：手写实现、数学对照和状态测试成立。
2. **教学实验完成**：98M 模型在声明的有限预算内真正训练，能恢复、能评估、能生成，保存实际曲线和环境信息。
3. **充分预训练完成**：在足量、审计过的数据和事先确定的评估协议上，完成大预算训练与能力评估。当前不以第二项冒充第三项。
