## 恢复训练的限制

| 问题 | 影响 |
| --- | --- |
| 日志尾行截断 | 恢复入口直接解析日志每一行；若进程中断留下半行 JSON，会触发 `JSONDecodeError` |
| 源码摘要检查 | 恢复入口核对配置、数据和设备，但未核对源码摘要；修改源码后恢复可能保留旧摘要 |

快照检查脚本另行核对源码摘要、模型状态与日志连续性。
