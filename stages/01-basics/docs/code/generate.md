# 自回归生成逐行讲解

源码：[aml/generate.py](../../aml/generate.py)。训练并行计算各位置 loss，生成则每次只消费最后位置 logits。该参考实现不使用缓存，每个新 token 重算最近上下文窗口。

| 源码行 | 含义 |
| --- | --- |
| 1 | 声明这是无 KV cache 的参考生成器。 |
| 3 | CLI 参数解析。 |
| 4 | 检查 temperature 是有限数值。 |
| 5 | 管理 checkpoint 路径。 |
| 7 | 张量运算与随机采样。 |
| 9 | 验证 tokenizer 指纹。 |
| 10 | 用 checkpoint 中的结构配置创建手写模型。 |
| 11 | 使用同一 BPE 规则编码 prompt、解码续写。 |
| 12 | 复用训练器的设备选择规则。 |
| 15 | 生成不需要梯度图。 |
| 16 | 接收模型、tokenizer、提示、生成 token 上限和温度。 |
| 17 | 生成长度不能为负，温度必须有限且非负。 |
| 18 | 参数无效就报错。 |
| 19 | 从模型参数获取设备，避免输入模型不在同一设备。 |
| 20 | 编码 prompt；空 prompt 用 EOS 作为非空起点。 |
| 21 | 单独收集续写，避免对原 prompt 再解码产生显示差异。 |
| 22 | 切换评估模式。 |
| 23 | 最多执行指定次数，每次产生一个新 token。 |
| 24 | 截取最近 context，增加 batch 维，构造 `[1,T]` 输入。 |
| 25 | 只取 batch 0、最后位置、实际词表范围的 logits；未使用词表槽位不参与生成。 |
| 26 | temperature 为零走确定性贪心分支。 |
| 27 | 直接选 logit 最大的 token。 |
| 28 | 正温度走随机采样分支。 |
| 29 | logits 除以温度再 softmax；温度越大通常分布越平。 |
| 30 | 按概率抽取一个 token，而非取最大值。 |
| 31 | EOS 是终止信号，不作为可见续写文本。 |
| 32 | 遇到 EOS 立即结束，即使还没用完 token 预算。 |
| 33 | 把新 token 送回下一轮上下文。 |
| 34 | 也把它加入待显示的续写列表。 |
| 35 | 一次性解码续写并接到原 prompt 后；这是原始 LM completion，不是 chat template。 |
| 38 | CLI 入口。 |
| 39 | 建立命令行解析器。 |
| 40 | 指定受信任的 checkpoint 路径。 |
| 41 | 默认英文故事开头。 |
| 42 | 默认续写预算为 100 个 token，而非 100 字符。 |
| 43 | 默认温度 0.8，并说明零温度用贪心。 |
| 44 | 明确允许的计算设备。 |
| 45 | 为随机采样提供种子。 |
| 46 | 读取参数。 |
| 47 | 设置随机种子。 |
| 48 | 先加载到 CPU，避免立刻把 optimizer 等无关状态占到 GPU。 |
| 49 | tokenizer 约定在 checkpoint 同目录。 |
| 50 | 核对其内容是否与训练时一致。 |
| 51 | 不一致就拒绝生成，防止权重 / ID 语义错配。 |
| 52 | 加载 BPE。 |
| 53 | 按保存配置创建模型并移动到指定设备。 |
| 54 | 加载已训练权重；生成不恢复 Adam。 |
| 55 | 执行生成并显示结果。 |
| 58 | 仅直接执行模块时启动 CLI。 |
| 59 | 调用 main。 |
